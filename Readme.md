# To run the code
Type this command line: docker-compose -f docker-compose.prod.yml up --build in the root hw2-app. Then, click the link: http://127.0.0.1:8000 in the terminal. The webpage will be show in this link

# To run the unit tests
You need to go to root of frontend and type: npm install --save-dev vitest @testing-library/svelte jsdom. This command line will ensure the necessary packages are installed or not. Then, you types npx vitest to run the test.
